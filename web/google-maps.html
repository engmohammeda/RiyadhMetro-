🔑 مفتاح Google Maps API مطلوب

هذه الصفحة تدمج شبكة مترو الرياض كاملة داخل Google Maps باستخدام Maps JavaScript API: المسارات بألوانها الرسمية فوق الخريطة، محطات تفاعلية ببطاقات معلومات، ومخطط رحلات مع اتجاهات متحركة. أدخل مفتاحك — يُحفظ محلياً في متصفحك فقط.

  • أنشئ مفتاحاً من Google Cloud Console وفعّل «Maps JavaScript API».
  • أو افتح الصفحة بالرابط: google-maps.html?key=YOUR_KEY
  • بديل بدون مفتاح: استورد dist/riyadh-metro.kml في Google My Maps.

اكتب محطة أو مكاناً (تُقبل الأسماء القديمة مثل «العليا»)، أو انقر محطة على الخريطة ثم اختر «من هنا / إلى هنا». الأزمنة تقديرية.

الأزمنة تقديرية (سرعة متوسطة + توقف لكل محطة + زمن التبديل). ساعات الخدمة والأسعار معلومات عامة — المرجع الرسمي تطبيق درب. المحطات ذات الإطار الأسود محطات تبادل؛ انقر على خط لإبرازه وعلى محطة لبطاقتها.
