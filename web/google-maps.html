مفتاح Google Maps API مطلوب
هذه الصفحة ترسم الشبكة ومخطط الرحلات مباشرة فوق Google Maps باستخدام Maps JavaScript API. أدخل مفتاحك (يُحفظ محلياً في متصفحك فقط)، أو افتح الصفحة بالشكل google-maps.html?key=YOUR_KEY.

احصل على مفتاح من Google Cloud Console مع تفعيل «Maps JavaScript API». البديل بدون مفتاح: استورد riyadh-metro.kml في Google My Maps.

الأزمنة تقديرية. المحطات ذات الإطار الأسود محطات تبادل. انقر على محطة لعرض معلوماتها.
