# أداة فحص الهوستات التوعوية — `host-audit`

أداة دفاعية/توعوية تفحص الهوستات وترصد **مؤشرات إساءة استغلال الوجهات المفروضة (Zero-Rating Abuse)** التي يعتمدها بائعو "النت المجاني"، وتُصدر تقريراً عربياً يشرح كل مؤشر.

> ⚖️ **تنويه قانوني:** هذه أداة توعوية/دفاعية. استخدمها فقط على ما تملك تصريح فحصه.
> الأداة **لا تُنتج** إعدادات تجاوز أو نقوب "مجانية" جاهزة؛ مهمتها الكشف والتوثيق والتوعية
> وإبلاغ المشغّلين لإصلاح الإعدادات الخاطئة. تجاوز الفوترة أو استخدام الشبكة بخلاف
> شروطها قد يُعدّ استخداماً غير مشروع وفق نظام مكافحة الجرائم المعلوماتية السعودي
> (المرسوم الملكي م/17) ونظائره. التفاصيل الكاملة: [`docs/free-internet-scams/`](../../docs/free-internet-scams/README.md).

## لماذا هذه الأداة؟

كل يوم يُخدع مئات الأشخاص بعروض مثل: *"أحوّل لك باقة الألعاب/السوشيال 60 ريال إلى إنترنت لكل التطبيقات بـ20 دولار شهرياً"*.
خلف هذه العروض ثغرات في إعدادات الشبكة (بروكسي وسيط مفتوح، تسامح مع تضليل SNI/Host، مسارات فوترة منفصلة).
هذه الأداة **تكشف هذه الإعدادات الخاطئة وتشرحها**، حتى:

1. يُعلم المواطن أن ما يشتريه نصب ومخاطر أمنية (مروره يمر عبر سيرفر البائع!).
2. يستخدمها الباحثون والمشغّلون لإغلاق الثغرات قبل استغلالها.

## ماذا تفحص؟

| الاختبار | الكود | يكشف |
|---|---|---|
| حلّ الاسم وقياس زمنه | `DNS_OK` | الحجب/التجاوز عبر DNS |
| بصمة TLS (الشهادة/البروتوكول/ALPN) | `TLS_INFO` | اختلاف المسار بين وجهة مفروضة وأخرى محسوبة |
| رؤوس HTTP (Via/X-Cache/…) | `PROXY_PATH` | وجود وسيط/كاش = مسار فوترة خاص |
| تحويلات البوابات | `CAPTIVE_PORTAL` | بوابات الدخول المستخدمة في الخدع |
| **اختبار CONNECT** | `OPEN_PROXY` 🔴 | بروكسي وسيط مفتوح = مخرج نفق "النت المجاني" |
| **تضليل رأس Host** | `FRONTING_TOLERANT` 🟠 | خادم يقبل SNI/Host مزوّر = أرضية خدع العبور |

## المتطلبات

- Python 3.8+ **فقط** (المكتبة القياسية — لا تثبيت أي شيء).

## الاستخدام

```bash
# فحص هوستات محددة وتوليد تقرير
python3 host_audit.py api.github.com github.com --report report.md

# فحص قائمة من ملف
python3 host_audit.py --file hosts.sample.txt --report report.md --json report.json

# الوضع السلبي (بدون اختبارات تفاعلية — مناسب للفحص الحذر)
python3 host_audit.py api.github.com --safe

# اختبار الأداة نفسها بدون شبكة
python3 host_audit.py --selftest
```

### الخيارات

| الخيار | الوصف |
|---|---|
| `-f, --file` | ملف هوستات (سطر لكل هوست، `#` للتعليقات) |
| `-t, --timeout` | مهلة الاتصال بالثواني (افتراضي 6) |
| `-w, --workers` | توازي الفحوصات (افتراضي 6) |
| `--safe` | فحص سلبي فقط (DNS/TLS/HTTP) |
| `--report` | حفظ التقرير Markdown |
| `--json` | حفظ النتائج JSON للتحليل الآلي |
| `--quiet` | ملخص قصير |
| `--no-banner` | إخفاء البانر القانوني |

## نصائح لمقارنة مسارات الفوترة (كشف خدع "النت المجاني")

1. أضف في الملف وجهة **داخل باقتك المفروضة** (نطاق ألعاب/سوشيال) ووجهة **عادية محسوبة**.
2. شغّل الفحص من **شريحة الهاتف نفسها** (نقطة اتصال/USB Tethering) وليس من واي فاي.
3. قارن في التقرير: بصمة TLS، رأس `Via`/`X-Cache`، وسلوك `CONNECT`.
4. أي اختلاف جذري بين المسارين يعني فوترة منفصلة — وهذه الأرضية التي تُباع لك بـ"20 دولار".

## القيود والأمان

- الاختباران التفاعليان (`CONNECT` و`FRONTing`) يرسلان طلبَي فحص فقط لكل هوست — لا حمولات.
- بعض الشبكات قد تحرّك الفحص النشط؛ استخدم `--safe` عند الحاجة.
- الأداة لا تحاول بأي شكل تجاوز الفوترة أو بناء نفق.
